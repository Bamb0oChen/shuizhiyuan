# 若水汇 · 前端概念原型

面向品质生活人群的水主题品牌网站。采用原生 HTML、CSS、JavaScript 与本地打包的 Three.js 0.180.0，无需构建步骤或安装依赖。当前视觉采用已选定的第三套「源境会客厅」方向。

## 本地启动

在项目根目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:4173 。请通过 HTTP 服务预览；直接以 file:// 打开会被浏览器的模块加载策略限制，无法体验实时水效。

## 已实现

- 四个完整视口章节：水的日常、私享体验、若水好物、品牌合作。最后一屏整合品牌合作与页脚。
- 桌面滚轮一次切换一屏，过渡后保留约 1 秒间隔；触屏原生滚动停靠，支持侧边导航、翻页按钮和键盘。
- 响应式首页，三组活动轮播、手动切换及自动播放暂停；首屏离开视口时暂停轮播，减少动态效果偏好下默认暂停。
- 首页右下角精选产品推荐。
- 活动分类、独立详情、每日打卡和筹备活动收藏。
- 「我的若水」完整页面：每日饮水记录、活动筛选、品牌同行与心愿单。
- 按品牌与产品记录 250 mL、500 mL 或自定义饮用量；今日总量、连续打卡与本周 / 本月 / 累计统计随记录更新。
- 品牌饮水计划、计划收藏与参与进度；饮水足迹可查看、撤销及恢复误填记录。
- 产品分类、独立详情与本机心愿单。
- 品牌理念、合作意向表单预览、合作伙伴工作台。
- 已替换为独立的水境、山野、茶室摄影风格素材，并接入用户提供的饮用水、爽肤水、面膜包装及品牌标识。
- Noto Serif SC 字体子集与 Tabler 图标本地打包，页面不请求第三方图片或字体服务。
- 实时水面折射与交互涟漪：鼠标经过或点击背景水面触发，触屏只响应轻触，不接管滑动；文字、产品和按钮不参与变形。
- 四屏共用一个 WebGL 渲染器，只更新当前屏；右上角「水面动效」可暂停。关闭页面、进入详情页或减少动态效果时停止；WebGL 不可用时保留静态背景。
- 哈希路由，浏览器前进后退可用。

## 原型边界

产品、包装与线下活动为概念方案；没有虚构已合作品牌、产品资质或功效。工作台数据均为演示数据。合作表单不联网、不保存、不提交联系方式。打卡、收藏、心愿单仅保存在当前浏览器；存储被禁用时回退到当前页面内存，并提示用户。

山泉品牌 A、天然水品牌 B 为品牌联动示例，不代表已建立商业合作。个人统计从空记录开始，按用户自主填写的饮水量汇总，不代表经核验的实际饮用量。旧版每日打卡保留为打卡日期，不自动补填饮用量；同一品牌同一天的多次饮水只计作一个计划记录日。计划进度统计加入后的对应品牌记录。

当前无后端、认证、支付、真实报名、品牌入驻审核或数据隔离。记录保存在本浏览器的 `localStorage`，尚不支持跨设备同步或汇总其他用户数据。上线前需确认品牌视觉、产品来源与资质、实际活动安排，并实现真实业务接口和企业权限隔离。

- `#/member/activities`：全部 / 进行中 / 已收藏活动。
- `#/member/brands`：各品牌的饮水足迹及品牌活动入口。
- `#/member/records`：饮水明细，支持时间筛选与撤销 / 恢复。
- `#/brand/spring`、`#/brand/natural`：示例品牌联动计划。
- 原 `#/activity/morning` 与顶部「我的若水」均接入新版页面。

## 实时水效

- `water-effects.mjs`：渲染器生命周期、纹理加载、当前屏切换与指针事件。
- `water-shader.mjs`：基于摄影纹理的水面折射、低幅流动与衰减涟漪；这不是完整的物理流体模拟。
- `water-model.mjs`：图片裁切、坐标归一化、渲染预算与涟漪队列。
- `vendor/three/`：固定版本的 Three.js ES modules、MIT 许可及来源信息。运行时不请求 CDN。
- 默认水景首屏、体验屏、产品屏、合作屏启用水面效果；含家具和玻璃杯的另外两张轮播保持静止，以免扭曲非水面物体。
- 桌面目标帧率上限 45，窄屏/触屏 30，省流模式 24；实际性能随设备变化。绘制像素与纹理尺寸都有上限。
